# Agent and app catalogue

Reference list of agents and the app each one records its work in, by department.
Use it to name a suggestion and to check that nothing obvious is missed. It is a starting list, not a limit.
Suggest an agent from this list only when the evidence shows the matching gap.

Tools are named by class (CRM, support desk, call recorder), not by product. Map each class to the product this team uses.

App shapes: Tracker board, Approval queue, Metrics dashboard, Document review workspace, Run log, Two-sided reconciliation.
